# Quantum Computing

Minimal starters for **PennyLane** and **Qiskit** (circuit demo + variational-style example).

## Structure

```text
Quantum Computing/
├── qiskit_pennylane_starter.py
├── requirements.txt
└── README.md
```

## Setup

```powershell
cd "Quantum Computing"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python qiskit_pennylane_starter.py
```

## Stack

numpy, pennylane, qiskit, qiskit-aer.
