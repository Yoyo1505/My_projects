# Loan Assessment System

Dual-model ML notebook: **loan approval classification** and **loan amount regression**, with sklearn pipelines.

## Structure

```text
Loan Assessment System/
├── data/
│   └── loan_approval_dataset.csv
├── notebooks/
│   └── Loan Assesment System.ipynb
└── README.md
```

## Setup

```powershell
cd "Loan Assessment System"
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
jupyter notebook notebooks/
```

## Stack

pandas, numpy, scikit-learn, matplotlib, seaborn.
