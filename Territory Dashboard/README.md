# Territory Dashboard

Interactive **territorial finance dashboard** with drill-down (division → PDC), account trees, cierres, and quarterly views.

This project includes **two runnable versions**:

1. **Streamlit (Python)** — full interactive app  
2. **Static HTML/JS** — always-on GitHub Pages demo (no server)

## 1) Streamlit version

### Structure

```text
Territory Dashboard/
├── app.py                 # Streamlit UI + compute engine
├── seed_demo_data.py      # Synthetic aggs generator
├── requirements.txt
├── MAPPINGS.md            # Full mapping reference
├── VERSIONS.md
├── README.md
├── .streamlit/config.toml
└── aggs/                  # Local data (gitignored parquets; regenerated by seed)
```

### Setup

```powershell
cd "Territory Dashboard"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Open **http://localhost:8501** (or the port Streamlit prints).

- No login.  
- If `aggs/` is missing or outdated (`version_seed < 2`), seed runs automatically.  
- Manual seed: `python seed_demo_data.py`

### Stack

Streamlit, Polars, Pandas, Plotly.

## 2) Static HTML/JS version

| File | Role |
|------|------|
| `../docs/territory/index.html` | UI (tabs: Resumen, Div/Terr, Cuentas, Cierres, Trimestres) |
| `../docs/territory/data/demo.json` | Compact synthetic snapshot |
| `../docs/index.html` | Portfolio landing |

**Hosting:** GitHub repo → Settings → Pages → Branch `main` → folder `/docs`.

Does **not** require you to keep Streamlit running.

### Refresh static data after changing the seed

From repo root (with aggs already built):

```powershell
python docs/_export_demo_data.py
```

Then commit the updated `docs/territory/data/demo.json`.

## Conceptual model (summary)

**Territorial hierarchy**

`Agrupa 1 → División → Territorio → Zona → Región → PDC`

**Accounting hierarchy**

`Grupo de Cuentas → Cuentas → PosPre`

**Measures**

`Real_2025`, `Real_2026` (cut at week SMR), `Plan_2026`, `Nvo_Plan_2026`, Forecast

Full tables: **[MAPPINGS.md](MAPPINGS.md)**.
